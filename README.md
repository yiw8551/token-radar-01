A token launch radar: a Node program that reads the sealed DefiLlama snapshot, ranks 198 pre-token protocols by an implied token value derived from the snapshot's own figures (category multiples taken from the median market-cap/TVL ratios of already-tokenized protocols, adjusted for 7-day TVL momentum and for how long each protocol has run with no token), and writes a ranked board plus a sortable, filterable dashboard with a detail view and a concrete farm plan for every protocol.

## Run it

`node main.ts` with `/input/snapshot.json` present; outputs land in `/output` (board.json, the dashboard with its data file, screenshots and dossier.json).
